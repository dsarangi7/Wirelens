# Skills

Agent skill files for this project, shared by every coding agent.

- `wirelens/SKILL.md`: full working knowledge (conventions, port names, cable and routing rules, rack JSON, adding a rack).

`.claude/skills/wirelens/SKILL.md` is the same file for Claude Code. When you change one, copy it to the other:

```powershell
Copy-Item .claude/skills/wirelens/SKILL.md skills/wirelens/SKILL.md
```
Confidential project notes are in `projects/<name>/SKILL-notes.md` and `projects/<name>/AGENTS.md` (local only).
